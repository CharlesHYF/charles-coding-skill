# 白盒测试用例（whitebox test）

> 白盒测试：基于代码内部实现，覆盖每个分支、边界条件、异常路径、循环边界。
> 目标：语句覆盖率 ≥ 80%，分支覆盖率 ≥ 70%。

## 通用白盒覆盖要求

| 编号 | 覆盖维度 | 覆盖要求 | 示例 |
| ---- | -------- | -------- | ---- |
| WB-01 | 分支覆盖 | 每个 if/else/switch 的所有分支至少命中一次 | 状态机的每种状态转换都触发 |
| WB-02 | 边界覆盖 | 循环 0 次、1 次、N 次 | 列表为空、单元素、多元素 |
| WB-03 | 异常覆盖 | 每个 try-catch / 错误返回路径 | 数据库断连、网络超时、非法输入 |
| WB-04 | 空值覆盖 | null/undefined/空字符串/空集合 | 传 null 参数、空列表 |
| WB-05 | 并发覆盖 | 共享资源的并发读写 | 并发扣库存、并发注册 |
