# docs/modules/ 目录说明

> 所有模块文档按系统级模块划分子目录，例如 `backend/`、`frontend/`、`daemon/`。
> 每个功能一个子目录，内含 `功能描述`、`接口信息`、`入参要求`、`返回`、`业务流程`、`异常与错误码`、`数据库表/字段` 等小节。

## 约定
- **新模块必须先写文档**，放在对应系统模块目录下，如 `docs/modules/backend/订单管理.md`
- 一个模块一个 `.md`，模块名称即为文件名
- 文档评审通过后再进入编码，代码实现须与文档一致
- 文档随功能变更同步更新
