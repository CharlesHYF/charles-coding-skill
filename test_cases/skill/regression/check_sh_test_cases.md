# 规范校验器（tools/check.sh）-- 回归测试用例

> 模块简介：把确定性编码规则变成会 fail 的检查，共八项，支持全量与增量两种范围
> 执行方式：`bash tests/run_tests.sh`
> 测试框架：Bash 断言脚本，用临时目录构造 fixture 后跑 check.sh 比对输出
